# Prototype inspiration

The approved specification pins the Monument direction. Pear's public landing page informed the editorial rhythm: short statements, mixed roman/italic display type and an honest FAQ. Inkwell's public page informed the idea of changing a sequence into parallel threads. Keystone's copy, brand geometry, arch and interface are original.

Public pages were read through web tools; a screenshot study of those reference sites was not completed. Visual verification focused on this local prototype through the Codex browser's Playwright surface. Calm repeated interactions follow the installed Emil and design-motion-principles references; the arch keystone is the only expressive entrance.
